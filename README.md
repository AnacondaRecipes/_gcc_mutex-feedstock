# Installing _gcc_mutex

Installing `_gcc_feedstock` from the main channel can be achieved by:

```
conda install _gcc_feedstock
```

It is possible to list all of the versions of `_gcc_feedstock` available on your platform with `conda`:

```
conda search _gcc_feedstock
```
